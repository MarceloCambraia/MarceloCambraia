## Featured Project

### APABB App — Donations & Volunteer Platform

A web and mobile platform developed for APABB, focused on donations,
volunteer management and administrative operations.

**Main technologies:**

`React` • `TypeScript` • `Supabase` • `PostgreSQL` • `Node.js` • `Google Cloud` • `Capacitor`

Some of the technical challenges involved:

- Payment API integrations
- PIX, boleto and card payment flows
- Authentication and access control
- PostgreSQL with Row Level Security
- Serverless backend with Supabase Edge Functions
- mTLS integration through a Node.js proxy on Google Cloud Run
- Android application packaging with Capacitor
- End-to-end testing with Cypress

[View APABB App](https://github.com/MarceloCambraia/apabb-app)
